EDSP-ESPACE TRANSPORT (TRANSPORT MANAGER) - Application, version 2 (23 tables)

POUR METTRE A JOUR (3 gestes)
1. Décompresse ce ZIP.
2. Sur GitHub, dans ton dépôt "espace-transport" : Add file > Upload files, glisse tous les fichiers, puis Commit changes.
3. Attends 2 minutes, ouvre l'application et fais Ctrl + F5.

Le fichier demo.html de l'ancienne version peut rester, il n'est plus utilisé.
config.js ne contient que la clé PUBLIQUE. Ne jamais y mettre la clé "service_role" ou "secret".

MOT DE PASSE OUBLIE : dans Supabase > Authentication > URL Configuration, mets dans "Site URL" l'adresse de l'application
(https://egnongrace445-bot.github.io/espace-transport/) et ajoute-la aussi dans "Redirect URLs".
CONNEXION PAR SMS : désactivée. Elle s'active dans config.js (sms:true) une fois un fournisseur SMS configuré dans Supabase.
